# Demo Skill Directory

The managed workflow Skill will live in this visible project-level directory. Its exact environment adapters are outside this demo.

The automatic loop may select, start, update, block, verify, and complete
technical Tasks through revision-checked transactions. It may also run
read-only Iteration readiness checks. It must stop before activation, material
SPEC decisions, product acceptance dispositions, waivers, replanning outcomes,
and Iteration completion. Those protected changes require an explicit owner
confirmation through `dogdouspec iteration confirm`.
